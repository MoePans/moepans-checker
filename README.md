# MoePans 测活助手 (`moepans-checker` v1.2.19)

面向 MoePans 站点的轻量级浏览器扩展（Manifest V3），用于通过**双轨众包测活**协助站长自动识别失效网盘分享、采集多级目录结构、估算真实文件总大小并提取分享者昵称。

## 核心特性

* **被动读页模式（默认开启，零额外请求）**：仅在用户从 MoePans 主动点击打开网盘链接时，由内容脚本读取网盘页面提示识别有效/失效并回传，不发起任何额外探测请求。
* **主动租约测活（用户可选开启 / 详情页手动「验证链接」）**：按服务端签发的 30 秒原子租约低并发探测（每页最多 5 条、并发 2、随机抖动），避免触发网盘限流。
* **10 大网盘多级目录树 + 截断 `+` 提示 + 点击按需懒加载**：
  * 现已支持 **10 大主流网盘**（夸克、UC、阿里、百度、天翼、迅雷、123、115、移动、**光鸭云盘**）的存活状态、多级目录与容量识别（其中光鸭云盘支持匿名测活、DFS 目录树展开与精确容量汇总）。
  * 单页统一 20 条，首次采样最多 4 层 / 12 次子请求 / 80 项，存在未展开目录或后续分页时自动标 `+`（如 `80+ 项`、`118.25+ GB`）。
  * 网页详情弹窗与扩展弹窗均默认收起目录，点击未采样文件夹的 **`展开加载`** 或底部的 **`加载更多...`** 即可单独拉取下一层/下一页（支持页码分页与游标分页），不从头重测。
* **内置可导出诊断日志**：扩展弹窗保留最近 100 条测活记录（附环境/版本/设备元信息），支持一键复制、导出 `.log` 与清空。

## 快速安装（Edge / Chrome 等 Chromium 浏览器）

前往 [GitHub Releases](https://github.com/MoePans/moepans-checker/releases/) 下载最新版 `.crx` 安装包或源码压缩包：

1. 打开浏览器扩展页（`edge://extensions` 或 `chrome://extensions`）并开启「开发人员模式」。
2. 将 `.crx` 文件直接拖入扩展页安装，或解压压缩包后点击「加载解压缩的扩展」选择目录。
3. 刷新 MoePans 站点页面即可自动连接（顶部显示「助手已就绪」）。

## 隐私与安全边界

* 仅在检测到 `<meta name="moepans-crowd-check" content="1">` 的 MoePans 站点激活页面通信桥梁，且页面 `window.postMessage` 严格校验 `window.location.origin` 同源边界。
* `rules.json` 通过 `excludedInitiatorDomains` 严格隔离，仅对扩展后台主动探测请求生效，绝不干扰用户正常浏览网盘网页。
* 除兼容已登录场景的必要情况外，探测均采用 `credentials: "omit"` 匿名模式，不收集或上传任何网盘账号 Cookie。
