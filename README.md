# MoePans 测活助手（Chrome / Edge 扩展）

基于 Manifest V3 的轻量客户端测活助手，采用**被动读页为主 + 服务端租约主动测活为辅**的双轨架构：

- **被动读页模式（默认开启）**：当你从 MoePans 点击某条资源跳转到夸克、百度、阿里、天翼、迅雷、123、UC 分享页时，插件顺手识别页面是否失效并静默回传，**零额外 API 请求**，不触发风控。
- **主动租约模式（可选开启）**：在插件弹窗或 MoePans 顶部开启后，浏览搜索结果时会自动向 MoePans 申请 30 秒原子租约（每页最多 5 条、最大并发 2），避免热点惊群。
- **隐私保护**：仅处理从 MoePans 页面点击或领租约的资源链接，不读取你的网盘 Cookie 或其他浏览记录。

## 本地快速安装（3 步）

1. 解压 `moepans-checker-extension.zip` 到任意固定文件夹。
2. 打开 **Edge**（`edge://extensions/`）或 **Chrome**（`chrome://extensions/`），开启右上角「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择解压后的文件夹即可自动生效。
